Listas com HTML5

Listas Ordenadas

Listas ordenadas são feitas com as Tags <ol> (ordered List) e <li> (list item). Lista ordenada é uma lista com ordem númerica a ser seguida (1,2,3... ; A,B,C... ; a,b,c... ; I,II,III... ; i,ii,iii...)
É possivel mudar o tipo de lista e também o número inicial usando <ol type="" start="">

Listas Não ordenadas

Listas não ordenadas são feitas com as tags <ul> (unordered list) e <li> (list item). Listas não ordenadas são aquelas que não tem uma ordem correta a ser seguida, por isso são listadas com marcadores simples (Circle, Disc, Square)
